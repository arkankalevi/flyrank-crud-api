# FlyRank W2 A1 — Task CRUD API

A simple CRUD API built with Python and FastAPI as part of the FlyRank AI Internship W2 A1 assignment.

The API manages a to-do task list using in-memory storage.

## Features

- Create tasks
- Read all tasks
- Read a single task
- Update tasks
- Delete tasks
- Input validation
- 404 handling
- Swagger UI documentation
- In-memory data storage

## Requirements

- Python 3.10+
- Git
